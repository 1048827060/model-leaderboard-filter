# 模型推荐器（小白版 · 抗刷分 · 实时 · 带性价比）

你打一句话说想干啥（「帮我写个周报」「写个爬虫代码」「看看这张图里有什么」），
它直接回你**前几名候选模型**，并区分**国产 / 国外**、标出**性价比**。

- 💬 **综合对话** / 💻 **代码生成** / 👁 **视觉理解**：三个专业榜，均来自
  **LMArena 官方「人类盲测匿名对战」**——真实用户投票、模型匿名，厂商无法预知题目
  或干预结果，业界公认**最刷不了分**的评测方式。
- **国产 vs 国外**：自动按模型/机构识别，列表里用绿色（国产）/蓝色（国外）标签区分。
- **性价比榜**：性价比 = 该榜 LMArena 分数 ÷ 参考均价（输入/输出每百万 token 美元，
  取自内置参考价表）。价格未知/开源自部署标「—」。便宜的国产模型往往在性价比榜领跑。

## 链接（已部署，手机可看）
> **https://1048827060.github.io/model-leaderboard-filter/**

手机浏览器收藏即可，每天（UTC 0/12 点）自动刷新。

## 怎么用
1. 打开链接，输入框写一句话说你想干啥，点「推荐模型」。
2. 自动列出该类别**前 5 名候选**，每项带：国产/国外标签、分数、价格、性价比（★最划算标在最前）。
3. 下方三个按钮（💬/💻/👁）可手动切换类别。
4. 点「展开完整榜单」可看三榜完整排名，支持 **只看国产/只看国外** 筛选，以及
   **按分数 / 按性价比** 排序；第四个标签 **💰 性价比** 直接给出通用性价比榜。

## 说明
- 数据源：LMArena 官方每日更新数据集 `lmarena-ai/leaderboard-dataset`（text/webdev/vision）。
- 价格为内置**参考价**（USD/百万 token），仅供性价比估算，实际以厂商官网为准。
- 标红含义：`样本不足·排名不稳定`（票数低于阈值）；`总分与分项背离·疑似异常`。
