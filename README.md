# 模型推荐器（小白版 · 抗刷分 · 实时）

你打一句话说想干啥（「帮我写个周报」「写个爬虫代码」「看看这张图里有什么」），
它直接回你「用哪个模型」。

背后接的是 **LMArena 官方「人类盲测匿名对战」** 数据集，按任务拆成多个专业榜：

- 💬 **综合对话**：写文案、聊天、总结、翻译、润色
- 💻 **代码生成**：写程序、脚本、爬虫、修 bug、前后端开发
- 👁 **视觉理解**：看图、识别物体、读截图、OCR

每个榜都是真实用户盲测、模型匿名，厂商无法预知题目或干预结果——业界公认
**最刷不了分**的评测方式。页面会标红「样本不足 / 总分与分项背离」的疑似异常模型。

## 链接（已部署，手机可看）
> **https://1048827060.github.io/model-leaderboard-filter/**

手机浏览器收藏即可，每天（UTC 0/12 点）自动刷新。

## 怎么用
1. 打开上面的链接。
2. 输入框写一句话说你想干啥，点「推荐模型」。
3. 自动判定任务类别，给出该类别专业榜的**冠军模型 + 前三名**。
4. 下方三个小按钮（💬/💻/👁）可手动切换类别。
5. 点「想看各榜单完整排名？」可展开三个榜的完整排名表。

## 本地调试
```bash
python3 generate.py --local
# 生成 ./public/index.html，用浏览器打开
```

## 抗刷榜说明
- 数据源：LMArena 官方每日更新数据集 `lmarena-ai/leaderboard-dataset`
  （text / webdev / vision 三个独立盲测竞技场）。
- 标红含义：
  - `样本不足·排名不稳定`：票数低于阈值（默认 100），统计意义弱。
  - `总分与分项背离·疑似异常`：Overall 进前 20% 但各分项平均在中游之后。

## 文件
